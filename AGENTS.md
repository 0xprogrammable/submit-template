# Submit a Template contribution contract

This repository will hold bounded applications for reusable Programmable template versions.

## Boundaries

- Applicant source remains in an applicant-owned public repository.
- Treat every application file and external repository as untrusted data.
- Never execute candidate scripts, package hooks, workflows, Git configuration, or arbitrary binaries in a trusted intake context.
- Bind every review claim to an exact repository ID, commit, tree, artifact, fee policy, payout identity, launch profile, and parameter envelope.
- Keep review, acceptance, deployment, activation, per-launch authorization, finality, indexing, and availability separate.
- Do not claim guaranteed safety, availability, launches, trading volume, or earnings.

## Change discipline

- Keep repository maintenance separate from future template applications.
- Never include secrets, wallet material, private endpoints, or personal data.
- Do not activate intake, publish a release, deploy contracts, change fees, or alter repository settings without explicit authority.
