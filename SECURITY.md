# Security

Report exploitable vulnerabilities through [GitHub private vulnerability reporting](https://github.com/0xprogrammable/submit-template/security/advisories/new).

Do not publish an unpatched exploit, credential, wallet secret, private endpoint, personal data, or instructions that place deployed systems or user funds at risk.

Public issues are suitable for documentation errors, broken links, and non-sensitive workflow problems.

This repository records applications and review evidence. Passing validation or review is not a safety guarantee or independent audit.
