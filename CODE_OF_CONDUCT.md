# Code of conduct

Programmable welcomes clear, good-faith technical participation.

Be respectful. Discuss the work rather than the person. Do not harass, threaten, discriminate, expose personal information, or pressure maintainers or applicants to bypass review and security boundaries.

Keep security reports private until a fix can be prepared. Do not publish credentials, wallet material, personal data, or an unpatched exploit.

Maintainers may edit, hide, lock, or remove contributions that violate these expectations and may restrict participation when necessary to protect contributors or the project.

Use GitHub's report tools for conduct concerns and do not repost personal data. Use this repository's private vulnerability reporting channel only when the report concerns a security vulnerability.
